Capacidades e Funcionalidades

Um agente local que tira o máximo de cada modelo, dos pequenos aos grandes MoE, com segurança e sem esconder o que fez.

100% Local e Privado

Os modelos, as conversas e os teus ficheiros ficam no teu computador. Não há telemetria nem contas. A pesquisa na web é opcional e só acontece quando a pedes.

Os teus dados não saem do PC

Um Agente que Faz o Trabalho

Pede uma tarefa num projeto e o Simplexity lê os ficheiros, cria ou edita só o que é preciso, executa scripts e confirma no disco que o resultado existe. Se algo falhar, diz-te o que falhou.

Ações verificadas no disco

Harness Cognitivo para Modelos Pequenos e MoE

Um orquestrador próprio guia o modelo passo a passo: escolhe as ferramentas que cada pedido justifica, verifica cada resultado, deteta repetições e reaproveita a cache do modelo. Nos modelos MoE grandes, mantém o essencial na GPU e põe os especialistas na RAM, para correrem numa GPU de 8 GB.

O que significam as quantizações?

As quantizações comprimem os números do modelo para poupar memória. Q4_K_M é o padrão recomendado (melhor equilíbrio entre velocidade, qualidade e tamanho). Q8_0 preserva fidelidade máxima a troco de mais VRAM. Q2/Q3 são ultraleves para sistemas com pouca memória.

FLUXO SIMPLES EM 3 PASSOS

Como Começar com o Simplexity

Sem registos na nuvem, sem comandos complexos no terminal. Pronto a usar em poucos minutos.

01

1. Transferir o Simplexity

Descarrega o instalador (.exe) ou a versão portátil (.zip) quando forem publicados. Instalação limpa no Windows 10 ou 11, sem serviços de fundo.

Ver opções de download
02

2. Escolher um Modelo de IA

Utiliza o catálogo integrado no programa ou no site para obter um ficheiro .gguf compatível (como Qwen, Gemma ou Llama), ou coloca qualquer modelo que já tenhas na pasta.

03

3. Abrir um Projeto e Pedir

Escolhe a pasta onde o Simplexity pode trabalhar e pede em linguagem natural: criar um script, corrigir um erro, organizar ficheiros ou diagnosticar o PC.

Só trabalha nas pastas que autorizas

Requisitos do Sistema & Informações Técnicas

MÍNIMO

• Windows 10 / 11 64-bit

• Processador x64 com 4 núcleos

• 8 GB de RAM (modelos de 4B, só CPU)

• 10 GB livres em disco (programa + 1 modelo)

RECOMENDADO

• 16 GB de RAM

• GPU NVIDIA com 8 GB de VRAM (ex.: RTX 3060/4060/5050)

• Disco SSD NVMe

• 32 GB de RAM para MoE grandes (26B–35B)
